# 🌸 PCOS Wellness Assistant

A beautifully designed, AI-powered wellness companion that helps women understand and manage PCOS through personalized lifestyle guidance, symptom assessment, and supportive daily plans.

---

## ✨ What This Project Does

### 🧬 PCOS Severity Assessment  
A guided, multi-step assessment that collects:  
- Age, BMI, weight  
- Lifestyle symptoms  
- Menstrual cycle data  
- Optional hormone values  

The app predicts **PCOS severity** using a trained ML model, categorized as:  
- 🌿 Mild  
- 🌸 Moderate  
- ❤️ Severe  

Each result includes a friendly, emoji-rich explanation.

---

## 📝 Personalized PCOS Wellness Plan  
The system generates a fully customized, AI-powered lifestyle plan including:  
- 🌅 Daily routine  
- 📅 Weekly habits  
- 🍽️ Diet recommendations  
- 🏃‍♀️ Exercise guidance  
- 💊 Optional supplement suggestions  
- 🌿 Lifestyle improvements  
- 🚫 What to avoid  
- 🔍 Tracking progress  
- 💖 A supportive motivational message  

The plan is warm, non-clinical, and easy to follow.

---

## 💾 Smart Data Persistence  
The app safely stores:  
- Assessment inputs  
- Severity result  
- Wellness plan  

This allows users to revisit their Todo plan anytime without repeating the assessment.
